# CountMatrix
<h2>Завдання / Task:</h2>
<h3>UA</h3>
Необхідно написати програму, яка для заданого двовимірного динамічного
масиву (матриці) цілих знакових чисел визначає, скільки разів кожне число
зустрічалося у матриці. Результат буде записаний у файл або виведений на екран. При
вирішенні завдання створити додаткові потоки для синхронізації яких застосовувати
розглянуті механізми. Наприклад для вирішення задачі в окремих обробляти парні та
не парні рядки, результат помістити в список чи вектор, який теж бути загальним
ресурсом, тож врахувати синхронізацію і для цього моменту. Матрицю заповнити
випадковими числами або прочитати з файлу.
<h3>EN</h3>
It is necessary to write a program that, for a given two-dimensional dynamic array (matrix) of integers, determines how many times each number appears in the matrix. The result will be written to a file or displayed on the screen. When solving the problem, create additional threads for synchronization of which the considered mechanisms should be applied. For example, to solve the problem, process even and odd rows separately, place the result in a list or vector, which will also be a common resource, so take into account synchronization for this moment. Fill the matrix with random numbers or read from a file.
